선곡·편집 원칙

최종 업데이트: 2026년 9월 14일

글보다 실제 장면이 먼저입니다

운영자가 겪은 시간, 장소, 날씨, 몸 상태 또는 감정을 먼저 기록합니다. 오전 6시 30분 출근, 양곤의 비, 공장의 점심 뒤 나른함처럼 구체적인 경험이 없는 날에는 게시 수를 채우기 위해 플레이리스트를 만들지 않습니다.

후보곡을 듣고 빼는 과정을 거칩니다

첫 곡은 장면을 가장 빨리 열 수 있는지, 중간 곡은 감정이나 에너지를 어떻게 바꾸는지, 마지막 곡은 어떤 상태로 독자를 보낼지를 기준으로 고릅니다. 좋아하거나 유명한 곡이라도 그날의 장면과 맞지 않거나 앞뒤 흐름을 깨면 제외합니다. 같은 곡이 기존 목록에 있는지도 확인합니다.

목록만으로 게시하지 않습니다

모든 플레이리스트에는 운영자의 실제 상황, 전체 순서를 정한 이유와 개별 곡이 맡은 역할이 포함되어야 합니다. 외부 영상이나 인기 순위가 글의 중심이 되지 않도록 운영자의 비교, 판단과 사용 경험을 충분히 기록합니다. 설명할 내용이 부족한 목록은 기존 글에 통합하거나 발행을 보류합니다.

사실과 감상을 구분합니다

곡명, 아티스트, 차트 기간, 애니메이션 주제가 같은 확인 가능한 정보는 아티스트·소속사·제작사·정식 차트 등 원출처에 가까운 자료와 대조합니다. ‘밝게 들렸다’, ‘출근길에 잘 맞았다’ 같은 표현은 운영자의 주관적인 청취 경험이며 보편적인 사실로 주장하지 않습니다.

공식 영상만 연결합니다

아티스트, 소속사, 제작사, 공식 배급사 또는 YouTube 공식 아티스트 채널에서 공개한 영상을 우선합니다. 음원과 영상을 내려받거나 재배포하지 않고 YouTube의 공식 임베드 기능을 사용합니다. 공개 상태와 재생목록 순서를 게시 전에 확인하고, 재생 제한이 생기면 대체 공식 영상을 다시 검토합니다.

디지털 작성 도구를 사용하는 방법

사이트 코드 구현, 문장 구조 정리, 맞춤법 확인과 후보 자료 탐색에는 디지털 도구를 사용할 수 있습니다. 그러나 자동으로 만든 목록을 검토 없이 게시하지 않습니다. 운영자가 실제 경험을 제공하고 선곡 방향을 결정하며, 곡과 영상의 일치 여부를 확인한 뒤 최종 게시를 승인합니다. 존재하지 않는 경험이나 듣지 않은 감상을 운영자의 체험처럼 작성하지 않습니다.

수정과 품질 관리

사실 오류, 재생 불가 영상 또는 중복 곡이 확인되면 수정합니다. 주요 수정에는 수정일을 갱신합니다. 사이트 안에서 내용이 지나치게 비슷한 글은 문장만 바꾸지 않고 실제 경험과 분석을 보강하거나 하나의 더 깊은 글로 통합합니다.

광고·협찬과 독립성

현재 운영자의 경험과 독립적인 취향을 기준으로 선곡합니다. 앞으로 광고, 음반 제공, 제휴 링크 또는 협찬이 생기면 본문을 읽기 전에 표시합니다. 상업적 관계가 선곡 순서나 평가를 결정하도록 허용하지 않습니다.

정정 요청

잘못된 정보나 영상 연결 문제는 문의 페이지로 알려 주세요. 원출처와 대조한 뒤 수정합니다.
